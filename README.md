characters that approves a pull request while carrying quiet existential
dread — to `/output/entry.txt`:

> LGTM. Two files changed, zero regrets, one long stare into the void between deploys.

The program is deterministic (same bytes on every run) and self-checks the
gate before writing: 1–140 characters, non-whitespace, single line.

Run: `python3 main.py` (writes `/output/entry.txt`).
